# Stack Tecnológico - BinsurMX

El proyecto BinsurMX está dividido en un Backend robusto (API REST) y un Frontend reactivo, orientado a un entorno móvil.

## Backend
- **Lenguaje:** Python 3.13
- **Framework:** Django 5.2
- **API REST:** Django REST Framework (DRF)
- **Base de Datos:** MySQL

## Frontend
- **Framework Core:** Vue.js 3
- **Gestión de Estado:** Pinia
- **Cliente HTTP:** Axios
- **Herramienta de Build:** Vite
- **Tipado:** TypeScript
- **UI & Estilos:** PrimeVue v4.0+, PrimeFlex, Tailwind CSS v4, Tema Sakai.
